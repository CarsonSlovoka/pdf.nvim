*pdf.txt*  View and edit PDFs inside Neovim

==============================================================================
INTRODUCTION                                              *pdf.nvim* *pdf-intro*

pdf.nvim opens PDF files in Neovim using Poppler (`pdfinfo`, `pdftotext`,
`pdftoppm`) and qpdf. It is not a WYSIWYG layout editor.

==============================================================================
REQUIREMENTS                                              *pdf-requirements*

- Neovim 0.12+
- Install with built-in |vim.pack| (no lazy.nvim)
- poppler-utils: pdfinfo, pdftotext, pdftoppm
- qpdf
- Optional: 3rd/image.nvim for in-buffer page raster
- Optional: pandoc + xelatex, or paps + ps2pdf, for CJK text export

==============================================================================
COMMANDS                                                  *pdf-commands*

:PdfOpen [file]           Open a PDF.
:PdfNext / :PdfPrev       Next / previous page.
:PdfPage {n}              Jump to page n.
:PdfMode image|text       Switch view mode.
:PdfInfo                  Show pdfinfo metadata.
:PdfExternal              Open in the system viewer.

:PdfExtract {range} [out] Copy page range to a new PDF.
:PdfMerge {file} [out]    Append another PDF.
:PdfSplit [dir]           Burst into single-page files.
:PdfRotate {deg} [pages]  Rotate 90/180/270/-90.
:PdfDeletePages {pages}   Drop pages (writes a copy).
:PdfReorder {order}       e.g. 3,1,2,4-z
:PdfCompress [out]        Recompress streams.

:PdfTextEdit              Extract full text into a buffer.
:PdfTextWrite [out]       Export that buffer as a new PDF.
:PdfForm                  Edit AcroForm fields.
:PdfFormApply [out]       Write field values via qpdf JSON.

==============================================================================
MAPS                                                      *pdf-maps*

Buffer-local in the viewer:

    j n         next page
    k p         previous page
    g / G       first / last
    i / t       image / text
    e           text layer editor
    f           form editor
    + -         zoom (image mode)
    o           system viewer
    r           reload
    q           close

==============================================================================
LIMITS                                                    *pdf-limits*

Text write-back cannot keep original fonts, columns, or figures.
It exports a new PDF from the extracted text.

Form fill depends on qpdf JSON (`--json`, `--update-from-json`)
and `--generate-appearances`. Odd form structures may need a
dedicated form tool.
